# Roadmap: волны 0 / 1 / 2

Сроки и бюджет взяты из оценки CPTO (v1: 3-4 месяца, 4-7 млн ₽; волна 2: 4-6 млн ₽).
Распределение v1 по волнам 0 и 1 ниже это предложение для обсуждения, а не факт.

| Волна | Недели | Бюджет (ориентир) | Цель | DoD |
|---|---|---|---|---|
| 0 Фундамент | 0-6 | 1-2 млн ₽ (из 4-7 млн ₽ на v1) | данные и правила готовы | S2T для кухни пройден; PIM по кухне загружен; 10 техкарт с владельцами, версиями и тестами; rule engine в CI; бриф v0; CI зелёный на GitHub |
| 1 Первый путь | 6-14 | 3-5 млн ₽ (остаток v1) | расчёт и базовый ЦПР на пилоте | расчёт без сотрудника на сайте Zetta Home; 3-4 варианта на референс; геометрия и планировки; базовый ЦПР; аукцион; harness v0; `pass^k` на фикстурах не ниже 50% |
| 2 Масштаб | 14-26 | 4-6 млн ₽ | категории, ИИ-эффект, надёжность | новые категории; Text2SQL на семантическом слое; песочница; LLM-as-judge откалиброван; `pass^k` на реальных кейсах не ниже 60% |

Параллельно с волной 0: контент референсов и вариантов (дизайн-направление), юридические
шаблоны ЦПР, договор с первыми подрядчиками.

## Кто делает

| Работа | Свои | Подрядчики | ИИ-агенты |
|---|---|---|---|
| Продукт, метрики, приоритеты | CPTO | нет | помощь с анализом |
| Библиотека техкарт и правил | эксперты Zetta Home | консультанты по технологиям | черновики, проверка полноты |
| PIM и S2T | дата-инженер | интеграция с источниками | генерация маппинга, тесты |
| Фронтенд сайта и кабинета | 1 лид | команда на фиксированный объём | компоненты, тесты |
| Ядро (геометрия, расчёт, ЦПР) | 1-2 бэкенд-инженера | нет | код под `AGENTS.md`, ревью человеком |
| Чертежи: шаблоны | проектировщик | студия чертежей | нет |
| Harness и evals | CPTO + инженер | нет | разработка с гейтами |
