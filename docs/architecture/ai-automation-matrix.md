# Матрица «процесс > ИИ / правила / человек»

| Процесс | ИИ | Правила (детерминированно) | Человек | Риск ИИ |
|---|---|---|---|---|
| Заполнение брифа из свободного текста | да, подсказки и разбор | валидация полей | подтверждает допущения | средний: додумывает ответы |
| Разбор фото и чертежа в контур | да, предложение с `confidence` | проверка замкнутости и площади | подтверждает размеры | высокий: ложная точность |
| Подбор референса и варианта | да, семантический поиск | фильтры по бюджету и площади | выбирает клиент | низкий |
| Подбор техкарты | нет | rule engine по условиям | эксперт ведёт библиотеку | недопустим |
| Объёмы, расход, смета | нет | расчёт по PIM и техкартам | проверка на выборке | недопустим |
| Цены и SKU | нет | только PIM | менеджер каталога | недопустим |
| Сборка ЦПР | нет | CPR Generator | эксперт утверждает | недопустим |
| Проверка ЦПР по чек-листу | да, как второй взгляд | code-based чек-лист первичен | эксперт | средний |
| Права доступа | нет | code-based ACL | админ | недопустим |
| Сравнение ставок на аукционе | да, резюме | сортировка и фильтры | клиент решает | низкий |
| Аналитика (Text2SQL) | да, по семантическому слою, read-only | ограничение до SELECT | аналитик читает | средний |
| Разработка (код, тесты, документы) | да, под `AGENTS.md` | CI, линтеры, evals | ревью человека | средний |
| Заказ, оплата, передача ТЗ | нет | write только с Idempotency-Key | подтверждение человеком | недопустим |

Правило: ИИ готовит вход и находит ошибки, а числа и обязательные операции считает код.
