# S2T-маппинг: каталог кухонь и материалов (шаблон + кухня)

S2T это gate: источник не попадает в DDS, пока по каждому полю нет правила, примера и
владельца. Ниже маппинг для кухонного каталога ZETTA. Поля источника предположительные
и подлежат сверке с реальной выгрузкой; колонки правил и проверок обязательны.

| Поле источника (ODS) | Поле DDS | Тип | Правило | Проверка (gate) | Пример |
|---|---|---|---|---|---|
| `article` | `catalog_sku.sku` | string | trim, upper, префикс источника | уникальность, не пусто | `ZT-KIT-0412` |
| `title` | `catalog_sku.name` | string | trim, схлопнуть пробелы | длина 3-200 | `Фасад Прага, белый` |
| `width`, `depth`, `height` | `*_mm` | int | если значение < 10, считать метрами и умножить на 1000 | 10 <= мм <= 5000 | `600` |
| `seat_width`, `seat_depth` | `seat_*_mm` | int, null | как габариты; null допустим только для не встраиваемых | для встраиваемой техники обязательны | `560` |
| `price` | `price_snapshot.price_rub` | decimal | убрать НДС-флаг, привести к рублям | > 0, не отличается от прошлого снимка более чем на 40% без флага | `18900.00` |
| `price_date` | `price_snapshot.snapshot_id` | string | `snap-YYYY-MM-DD-<источник>` | один снимок на загрузку | `snap-2026-11-03-zetta` |
| `category` | `catalog_sku.category` | enum | справочник сопоставления категорий | значение есть в справочнике | `kitchen_base_cabinet` |
| `in_stock` | `availability` | enum | `Y/N/ORDER` > `in_stock/out/made_to_order` | значение из набора | `made_to_order` |

## Что проверяется до загрузки

1. Ни одного SKU без габаритов и цены.
2. Нет дублей SKU внутри источника и между источниками (конфликт отдаётся человеку).
3. Единицы приведены к мм и рублям.
4. Для каждой правки правила S2T есть версия и владелец.

Автоматическая проверка (волна 0): тест по выгрузке, который падает при нарушении любого
из четырёх пунктов.
